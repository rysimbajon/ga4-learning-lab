# GA4 Learning Lab

A small Next.js website designed as a practical Google Analytics 4 sandbox.

## Run locally

Requirements:
- Node.js 18+

Install:
npm install

Run:
npm run dev

Open:
http://localhost:3000

## Suggested learning path

1. Create a GA4 Web Data Stream.
2. Add the Google tag.
3. Verify page_view in DebugView.
4. Add Google Tag Manager.
5. Track product views.
6. Track internal search.
7. Track downloads.
8. Track form interactions.
9. Add a dataLayer.
10. Create custom event parameters.
11. Mark selected events as key events.
12. Build Explorations.
